# Datos de demostración para los reels

Lo que se crea en producción para poder grabar. Todo **privado**, para que nadie
se apunte sin querer: una privada sale en el listado con la etiqueta «Privada»,
pero solo reserva quien sabe la contraseña. **Al acabar de grabar, se retira**
(«Retirar del portal» la devuelve a borrador) **o se cancela si ya no hace
falta**.

Las contraseñas no se apuntan aquí: viven en la gestión de cada partida.

Reglas para inventar datos:

- Nada de «prueba», «test» ni «demo» en lo que se ve.
- Títulos y tramas **propios**: nada de módulos publicados ni personajes de otros.
- Fechas a **2–4 semanas vista**, a una hora normal de juego, para que la mesa
  siga abierta mientras se graba.
- Lo que diga la descripción tiene que ser algo que la web hace (por ejemplo,
  «hilo de mesa», no «chat»).
